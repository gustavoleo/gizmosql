Windows first run

GizmoSQL is ready

Install complete. The sample database is installed at C:\ProgramData\GizmoSQL\samples\gizmosql-demo.duckdb.

  1. Open GizmoSQL UI from the Finish screen or Start Menu.
  2. Use the demo connection details below.
  3. Run the first query.

1. Welcome

Core is installed to C:\Program Files\GizmoSQL\. The bundled demo database is machine-wide so every Windows user gets the same path.

Demo server shortcut: Start Menu > GizmoSQL > Launch Demo Server

2. Query in GizmoSQL UI

  1. Open GizmoSQL UI. The default launcher also attempts to start the demo server automatically.
  2. If the demo server is not already running, use Start Menu > GizmoSQL > Launch Demo Server.
  3. Create or open a connection with:
    • Host: 127.0.0.1
    • Port: 31337
    • Username: gizmosql_user
    • Password: gizmosql_password
    • TLS: Off
  4. Run:
SELECT customer_name, order_total
FROM demo_recent_orders
ORDER BY order_total DESC
LIMIT 10;

3. Query in Power BI

  1. Restart Power BI Desktop after connector installation.
  2. Select Get Data > Database > GizmoSQL.
  3. Enter host 127.0.0.1 and port 31337.
  4. Authenticate with gizmosql_user / gizmosql_password.
  5. Browse the demo schema or paste the sample query above.

4. Query from CLI / DBeaver

Local connection details:

  • Host: 127.0.0.1
  • Port: 31337
  • Username: gizmosql_user
  • Password: gizmosql_password
  • Database file: C:\ProgramData\GizmoSQL\samples\gizmosql-demo.duckdb
gizmosql_client --host 127.0.0.1 --port 31337 --username gizmosql_user --password gizmosql_password
SELECT region_name, SUM(order_total) AS revenue
FROM demo_recent_orders
GROUP BY 1
ORDER BY revenue DESC;

5. Troubleshooting

Demo server fails

Run the Start Menu launcher again and read the PowerShell window. It checks for a missing database, missing server executable, and port 31337 conflicts before the server starts.

UI missing

Re-run GizmoSQL-Setup-x64.exe and keep GizmoSQL UI checked, or install the advanced/manual UI MSI.

Connector not visible

Restart Power BI Desktop. If it still does not appear, re-run setup with Power BI Connector selected.
